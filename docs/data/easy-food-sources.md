# かんたん食品・標準レシピ 初期データ根拠

確認日: 2026-10-26

## この文書の役割

かんたん食品と標準レシピの初期seedに使用する、表示名、文部科学省食品コード、標準重量、レシピ材料、情報源を記録する。

栄養値はNutriAIへ取り込んだ文部科学省食品成分データの100g当たりの値を使い、次の式で計算する。

```text
摂取分の栄養値 = 100g当たりの栄養値 × 使用重量g ÷ 100
```

この文書にあるカロリーはseed内容のレビュー用であり、DBへ計算結果を固定保存しない。アプリでは食品成分データから都度計算する。

## 共通の情報源

- 文部科学省 食品成分データベース  
  https://fooddb.mext.go.jp/
- 農林水産省「食事バランスガイド SV早見表」  
  https://www.maff.go.jp/j/syokuiku/zissen_navi/balance/chart.html

SV早見表は、ご飯Sを100g、Mを150g、Lを200g、6枚切り食パンを60g、卵1個を50g、冷奴を絹ごし豆腐150g、牛乳を200gとしている。本データでは、これらを日常的な量の根拠として採用する。

## 農林水産省SV早見表の全体確認

SV早見表に掲載された主食、副菜、主菜、牛乳・乳製品、果物の全項目を確認した。単品だけでなく、丼、麺、パン料理、汁物、炒め物、煮物、揚げ物など、今後「かんたん食品」や「標準レシピ」を増やす際の候補が広く含まれている。

用途は次のように整理する。

- ご飯、パン、卵、豆腐、牛乳などは、日常的な1食分の重量を決める根拠として使う。
- 親子丼、カレー、焼きそば、肉じゃがなどは、料理名と主材料の標準的な構成を決める参考にする。
- 利用頻度が高い料理から順に採用し、早見表の全料理を初期seedへ一括登録しない。

早見表に記載されるのは主材料であり、油、調味料、衣、たれなどが省略される料理がある。そのため、料理全体の栄養計算を早見表だけで完結させない。標準レシピでは、早見表を1食分と主材料の根拠にし、調味料を含む分量は農林水産省のレシピやメーカー公式レシピなど、別の出典で補う。

## 注意事項

- 標準重量は商品の内容量や家庭の盛り付けを保証するものではない。
- 「1丁」「1個」「1本」など重量差が大きい単位には、計算重量を併記する。
- 商品バーコードから記録する将来機能では、この標準値より商品の栄養表示を優先する。
- レシピのメーカー商品を文科省の汎用食品へ対応付ける場合、その値は近似であることを表示する。
- 出典ページの内容や文科省データを更新した場合は、確認日と計算値を見直す。
